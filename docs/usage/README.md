# طرز استفاده

عملیات روزمره از trait روی مدل، و تنظیمات از فاساد:

```php
use Karnoweb\Translation\Concerns\HasTranslation;
use Karnoweb\Translation\Facades\Translation;
```

هر صفحه در صورت نیاز سه بخش دارد: **قوانین**، **خطاها**، **نتیجه ذخیره‌شده**.
