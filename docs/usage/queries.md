# کوئری و جستجو

```php
// مدل‌هایی که حداقل یک ترجمه در لوکال fa دارند
Brand::query()->withTranslatedIn('fa')->get();

// مدل‌هایی که کلید title را در fa دارند
Brand::query()->withTranslatedInForKey('title', 'fa')->get();

// جستجو روی value همهٔ ترجمه‌ها (LIKE)
Brand::query()->search('عنوان')->get();
```

اگر locale به اسکوپ‌ها داده نشود، از لوکال جاری استفاده می‌شود.

## قوانین

- `search` روی `translationsPure` است؛ همهٔ لوکال‌ها را می‌گردد.
- برای لیست ادمین معمولاً `with('translationsPure')` را eager-load کنید تا N+1 نشود.
- برای ویترین با لوکال ثابت، `translations` کافی است.

## خطاها

اسکوپ‌ها استثنای دامنهٔ اختصاصی پرتاب نمی‌کنند؛ نتیجهٔ خالی یعنی شرط برقرار نیست.

## نتیجه ذخیره‌شده

این اسکوپ‌ها فقط فیلتر می‌کنند؛ ردیف جدیدی نمی‌سازند.
